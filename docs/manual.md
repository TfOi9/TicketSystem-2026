# TicketSystem 用户手册

## 1. 系统概述

TicketSystem 是一套完整的火车票查询、购买和管理系统。采用**客户端-服务端架构**，图形客户端通过局域网连接服务端，支持以下核心功能：

- 火车票直达查询与换乘查询
- 在线购票（支持候补队列）
- 订单管理与退票
- 管理员列车管理
- 管理员用户管理

## 2. 启动系统

### 2.1 启动服务端

```bash
./build/server
```

服务端启动后会在终端显示运行状态。首次启动会自动创建 root 管理员账号（用户名 `root`，密码 `sjtu`）。

### 2.2 启动图形客户端

```bash
./build/client_gui
```

客户端启动后会自动搜索局域网内的服务端。底部状态栏会显示连接状态：
- 「正在发现服务器...」→ 正在搜索
- 「发现服务器，正在连接...」→ 找到服务端
- 「已连接」→ 连接成功，可以正常使用
- 「未发现服务器」→ 请检查服务端是否已启动

## 3. 用户账号

### 3.1 注册

1. 点击顶栏右侧「注册」按钮
2. 填写用户名、密码、姓名、邮箱
3. 点击「注册」提交

新注册用户默认权限等级为 1（普通用户）。

### 3.2 登录

1. 点击顶栏右侧「登录」按钮
2. 输入用户名和密码
3. 点击「登录」

登录成功后，顶栏右侧会显示当前用户名和下拉菜单。

### 3.3 退出登录

点击用户名下拉菜单 →「退出登录」，或直接关闭客户端窗口（会自动发送退出命令）。

### 3.4 查看个人信息

点击用户名下拉菜单 →「个人信息」，可以查看用户名、姓名、邮箱和权限等级。

## 4. 查询车票

### 4.1 直达查询

1. 在首页左侧查询表单中输入**出发站**（例如「上海虹桥」）和**到达站**（例如「北京南」）
2. 选择**出发日期**（2026年6月1日 至 2026年9月30日）
3. 点击「查询车票」

查询结果将以表格形式展示：
- **车次名**：列车编号，蓝色可点击
- **出发站 / 到达站**：起始和终点站名
- **出发时间 / 到达时间**：实际出发和到达时间，含跨日标记（+1d）
- **历时**：行程总时长
- **价格**：票价（元）
- **余票**：当前可售余量

### 4.2 换乘查询

1. 勾选查询表单中的「换乘查询」复选框
2. 其他步骤与直达查询相同
3. 系统会返回最优换乘方案，车次名显示为「车次A → 车次B」格式

### 4.3 换向

点击「换向」按钮可以快速交换出发站和到达站。

### 4.4 查询列车时刻表

在车票列表中点击任一车次名（蓝色链接），即可查看该列车在当前查询日期下的完整时刻表，包括各站到达/出发时间、累计票价和区间余票。

## 5. 购买车票

1. 在车票列表中，点击目标车次行的「购票」按钮
2. 弹出购票确认对话框，显示车次信息、单价和余票
3. 选择**购买张数**（1-5张）
4. 可选：勾选「无票时加入候补队列」
   - 不勾选：余票不足时购买失败
   - 勾选：余票不足时自动进入候补队列，有票时优先分配
5. 点击「确认购买」

**注意**：购票前必须先登录。如果未登录，系统会提示先登录。

## 6. 订单管理

### 6.1 查看订单

1. 点击顶栏「订单」按钮
2. 页面会自动加载当前用户的所有订单

订单表格包含以下信息：

| 列名 | 说明 |
|---|---|
| 序号 | 退票时使用的编号 |
| 车次 | 购买的列车编号 |
| 出发站 / 到达站 | 行程起始和终点 |
| 出发时间 / 到达时间 | 实际时间 |
| 价格 | 单价（元） |
| 张数 | 购买数量 |
| 状态 | 已购 / 待候 / 已退 / 无效 |
| 操作 | 退票按钮（仅已购和待候订单显示） |

状态颜色说明：
- 🟢 **已购**：购买成功，已分配座位
- 🟡 **待候**：在候补队列中等待
- 🔴 **已退**：已成功退票
- ⚪ **无效**：异常状态

### 6.2 退票

1. 在订单页面，找到要退票的订单
2. 点击「退票」按钮
3. 确认对话框显示订单详情
4. 点击「确认退票」

退票成功后系统会自动刷新订单列表。退票会释放座位，候补队列中的后续订单将自动尝试分配。

## 7. 管理员功能

管理员功能仅对权限等级 ≥ 2 的用户可见。root 用户（权限等级 10）拥有全部管理权限。

### 7.1 进入管理页

登录管理员账号后，顶栏会出现「管理」按钮，点击进入。

### 7.2 列车管理

管理页上半部分为列车管理区：

| 操作 | 说明 |
|---|---|
| **查询列车** | 输入列车编号和日期，点击「查询列车」查看详情 |
| **添加列车** | 点击「添加列车」弹出表单，填写完整列车参数后提交 |
| **发布列车** | 输入列车编号，点击「发布列车」使其可被查询和购票 |
| **删除列车** | 输入列车编号，点击「删除列车」（需确认，仅未发布的列车可删除） |

**添加列车表单字段说明**：

| 字段 | 格式 | 示例 |
|---|---|---|
| 列车编号 (-i) | 字母+数字或下划线 | G101 |
| 站点数量 (-n) | 2-100 | 3 |
| 座位总数 (-m) | 1-100000（单车总座位） | 1000 |
| 站点列表 (-s) | 以 \| 分隔，N个站 | 上海虹桥\|南京南\|北京南 |
| 各段票价 (-p) | 以 \| 分隔，N-1段 | 114\|514 |
| 始发时间 (-x) | hh:mm | 08:00 |
| 行驶时间分 (-t) | 以 \| 分隔，N-1段 | 600\|600 |
| 停靠时间分 (-o) | 以 \| 分隔，N-2段 (2站时填 _) | 5 |
| 发售起始 | 2026年6-9月 | 06-01 |
| 发售截止 | 2026年6-9月 | 09-01 |
| 列车类型 (-y) | G/D/T/K | G (高铁) |

### 7.3 用户管理

管理页下半部分为用户管理区：

| 操作 | 说明 |
|---|---|
| **查询用户** | 输入用户名，点击「查询用户」查看其资料 |
| **添加用户** | 输入用户名，点击「添加用户」弹出表单（需填写密码、姓名、邮箱、权限等级） |

权限等级说明：
- 0：受限用户
- 1：普通用户
- 2：管理员
- 10：超级管理员（root）

## 8. 常见问题

**Q: 客户端显示「未发现服务器」？**
A: 请确认服务端已启动，且客户端和服务端在同一局域网。也可以检查防火墙设置。

**Q: 点击「购票」提示「请先登录」？**
A: 购票需要登录账号。请先在顶栏右侧登录。

**Q: 查询车票无结果？**
A: 可能原因：1) 该线路暂无已发布的列车；2) 出发日期不在列车发售日期范围内；3) 车站名称拼写不一致。

**Q: 管理员看不到「管理」按钮？**
A: 需要登录权限等级 ≥ 2 的账号。普通注册用户权限为 1，不显示管理功能。

**Q: 为什么无法删除某列车？**
A: 已发布的列车无法删除。请确认列车处于未发布状态。

## 9. 快捷操作提示

- **交换出发/到达站**：查询表单中点击「换向」按钮
- **换乘查询**：勾选查询表单中的「换乘查询」复选框
- **更换日期**：日期输入框支持下拉日历选择
- **表格排序**：点击车票列表/订单列表的表头可排序
